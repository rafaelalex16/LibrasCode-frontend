# Trilha de aprendizagem — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a Trilha fixa por 5 módulos com tutorial guiado, exercícios de código corrigidos pela saída e pergunta de conceito, com progresso real.

**Architecture:** Conteúdo em dados TypeScript; correção pura (comparar saída/comando obrigatório) separada da execução (reaproveita `executarPython` da IDE); progresso em `localStorage` com assinatura para as telas.

**Tech Stack:** React 18 + TypeScript + Tailwind, Monaco (`@monaco-editor/react`), Pyodide via `src/ide/executarPython.ts`, VLibras via `src/vlibras/vlibras.ts`.

**Spec:** `docs/superpowers/specs/2026-11-18-trilha-design.md`

## Global Constraints
- Todos os módulos abertos desde o início, numerados 1–5 na ordem recomendada.
- Textos em português; explicações dos passos em estrutura SOV.
- Sem novas dependências; o projeto não tem executor de testes — a lógica pura é testada com script Node (rolldown) fora do repositório e as telas no navegador.
- Comparação de saída ignora espaços no fim das linhas e linhas vazias no fim.

## Review Focus
- Código correto com `print` extra de espaço no fim ou linha vazia final → deve passar.
- Saída certa sem usar o comando exigido (ex.: `print("1\n2\n3")` em exercício de `for`) → reprova com mensagem que diz qual comando usar.
- Comando exigido só dentro de comentário ou texto (`# for`) → não conta como uso.
- `localStorage` indisponível ou com JSON inválido → a Trilha abre com progresso zerado, sem quebrar.
- Laço infinito ou erro de Python no exercício → mostra a explicação em Libras e conta tentativa, sem marcar concluído.

### Task 1: Conteúdo dos módulos
**Files:** Create `src/trilha/conteudo.ts`
**Produces:**
- `interface PassoTutorial { titulo: string; explicacaoSOV: string; exemplo?: string; termos: string[] }`
- `interface Exercicio { id: string; enunciado: string; codigoInicial: string; entradas: string[]; saidaEsperada: string; precisaUsar?: string; dica: string }`
- `interface PerguntaConceito { pergunta: string; opcoes: string[]; correta: number; explicacao: string }`
- `interface Modulo { id: string; numero: number; titulo: string; resumo: string; passos: PassoTutorial[]; exercicios: [Exercicio, Exercicio]; pergunta: PerguntaConceito }`
- `export const modulos: Modulo[]` (5 módulos: mostrar-na-tela, variaveis-entrada, condicoes, repeticao, listas); `export function buscarModulo(id: string): Modulo | undefined`
- [ ] Escrever os 5 módulos (3–4 passos, 2 exercícios, 1 pergunta cada); `termos` usam nomes existentes no glossário.
- [ ] Verificar: script Node confere que todo `termos[]` existe no glossário e que a solução de referência de cada exercício (no script) produz `saidaEsperada` no Pyodide.

### Task 2: Correção

**Consumes:** `Exercicio`. **Produces:** `normalizarSaida(texto: string): string`; `usaComando(codigo: string, comando: string): boolean`; `corrigir(exercicio: Exercicio, codigo: string, saida: string): { aprovado: boolean; motivo?: string }`
- [ ] Testes (script Node): saída com espaços no fim/linhas vazias finais passa; saída diferente reprova com motivo; `precisaUsar: "for"` com `# for` em comentário ou `"for"` em texto reprova; uso real passa.
- [ ] Implementar (`usaComando` remove comentários e textos entre aspas e procura a palavra inteira).

### Task 3: Progresso
**Files:** Create `src/trilha/progresso.ts`
